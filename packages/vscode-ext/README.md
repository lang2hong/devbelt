# DB Client

All-in-one Database Client for VS Code.

## Features

- Manage multiple database connections (MySQL, PostgreSQL, SQLite first)
- Browse databases, tables and columns in the explorer tree
- Run SQL queries with structured result display

## Usage

1. Click the **DB Client** icon in the activity bar.
2. Click **+ Add Connection** to create a connection.
3. Expand the connection to browse databases/tables.

## Requirements

- VS Code ^1.85.0
