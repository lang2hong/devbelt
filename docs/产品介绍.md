# DevBelt 产品介绍

DevBelt（`devbelt-db-client`）是集成在 VS Code 中的数据库开发工具，目标是减少编辑器与独立数据库工具之间的切换，覆盖连接管理、SQL 编辑执行、数据操作、结构设计、导入导出、2FA/TOTP 验证器、个人连接同步（端到端加密）、Redis、Elasticsearch 与 AI 辅助的完整工作流。

## 当前可用功能

以下功能已接入 extension activation；命令/视图注册有自动化测试覆盖，但**尚未通过干净 Profile VSIX 安装版 smoke test**（见 [发布与运维 §1.2](发布与运维.md)）。

### 本地数据库（无需登录）

| 能力 | 说明 |
|---|---|
| 多数据库引擎 | MySQL、SQLite、PostgreSQL 本地连接完整可用（本地连接不走权益门禁）；跨设备同步为登录后 Pro 权益 |
| 连接管理 | 新建/编辑/删除连接、分组管理、测试连接（表单内按钮）、SSH 隧道 |
| SQL 编辑 | 语法补全、CodeLens、格式化、执行、取消；`.sql` 静态诊断（缺 WHERE、危险 DDL、NOT IN 子查询、SELECT *、方言不符，可按规则配置） |
| 查询洞察（0.2.0） | 可视化 EXPLAIN（MySQL / PostgreSQL / SQLite 计划树、节点详情、告警、原始计划）、AI 解释计划、规则索引建议（仅建议不执行）、本地历史慢查询分析、数据字典导出（Markdown / HTML） |
| 结果视图 | 表格展示、筛选排序、受控行内编辑、多结果集 |
| 数据操作 | CSV/JSON/XML/XLSX/SQL 导入导出、库间数据传输 |
| 结构工具 | 表设计器、DDL（建/改/删表/列/索引/外键/触发器/视图/例程/事件）、ER 图 |
| Schema 工具 | Schema 对比、同步 SQL 生成 |
| 本地辅助 | 查询历史、审计日志、定时备份、连接池状态、服务器仪表盘、对象搜索 |
| 安全特性 | 凭据存入 VS Code `SecretStorage`、只读模式、生产环境写保护 |
| 验证器（2FA/TOTP） | 本地动态口令：粘贴 otpauth 链接 / 二维码图片录入、分组、标签、搜索、编辑删除、复制、导出；密钥只存 OS 密钥库、不下发界面。多设备同步规划中（P6） |

## 开发中

### 个人连接同步（P2）

在同一账号设备间端到端加密同步个人连接配置。

- **底层组件已实现**：E2EE 密码学（DEK/HKDF/AES-GCM/Ed25519/Argon2id Worker/恢复码）、envelope 封装、密钥生命周期、协议客户端、状态/映射/outbox 持久化、同步引擎、出站变更生成器、本地变更协调器、会话生命周期组件均已实现并有单元测试。
- **服务端**：状态、record feed、签名验证、nonce 防复用、幂等回执、配额、换钥、恢复、销毁、重置协议已实现并注册。
- **已实现（代码）**：类型化同步基础设施（四实体 typed ref）、关系安全 codec、apply 拓扑 + unresolved reconcile、全类型 mutator、路径校验 API、受控 session 接线、初始化/解锁/换钥/恢复/销毁/重置 UI、首次 pull 调度、冲突持久化与解决 UI、本机路径覆盖与「需要配置」提示均已完成。
- **待完成**：双设备安装版验证（B6 矩阵全 pass，见 [发布与运维 §6/§7](发布与运维.md)）。
- **v2 范围**：连接 + 分组 + 保存查询 + 查询文件夹全量同步，树内容跨设备一致；本机路径字段随 E2EE 密文同步（`connectionUrl`/`sqliteCommand` 可能含凭据，已由产品方确认接受）。
- 登录仅认证身份并获取权益，不等于同步已解锁；个人同步需要显式输入同步口令（SMP）。
- 自动同步默认关闭（`devbelt.sync.autoSync`）：开启后本地变更（连接/分组/保存查询/查询文件夹）自动同步；关闭时仅在「立即同步 / 拉取 / 推送」时同步。

完整规格见[P2 v2 工作包文档](工作包/P2-个人同步-v2.md)。

- AI 能力（P9）：ai-core 双通道（自带 Key / 服务端代理 parse-and-forward + 单段月额度）；AI Chat 面板（独立面板，流式/会话历史/schema 上下文/Context 明细）；NL2SQL（`Alt+A` 生成 + 意图复述/假设状态条 + "在 Chat 中细化"回路 + ENUM/字典映射 + 大库预筛）；SQL 解释/优化（含只读 EXPLAIN）；错误诊断（敏感信息双重阻断）；数据问答（样本默认不发、确认后打码）；表设计 AI 生成/审阅（结果回 Chat）；Inline 补全（`Alt+/` 手动触发，默认关）。**待 F5 真机与多模型手工矩阵**（发布硬门禁）。见 [P9 工作包文档](工作包/P9-AI.md)。
- Redis 客户端（P7）：连接管理（standalone/Cluster/Sentinel、ACL、SSL/TLS、SSH 隧道、只读）、服务器状态/慢日志、CLI 控制台（补全/危险命令二次确认/只读拦截）、SCAN 分页键浏览与分隔符折叠、string/hash/list/set/zset/stream 查看编辑、树内键导航、命令日志、字节级 hex。**待表单端到端 UI 走查**（发布硬门禁）。见 [P7 工作包文档](工作包/P7-Redis客户端.md)。
