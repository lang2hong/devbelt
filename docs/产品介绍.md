# DB Client — 产品介绍

**All-in-one Database Client for VS Code**，对标 Navicat / [database-client](https://database-client.com)。在编辑器内完成数据的连接、查询、编辑、导入导出、设计、对比与同步。

## 产品定位

- 面向**数据库开发与运维**人群，把常用数据库操作带进 VS Code，无需切换独立客户端。
- 覆盖 MySQL、PostgreSQL、SQLite，规划中支持 Redis、ElasticSearch。
- 提供「查询 → 编辑 → 运维 → 同步」的完整闭环。

## 核心能力

| 能力 | 说明 |
|---|---|
| **多数据库** | MySQL、PostgreSQL、SQLite（Redis、ElasticSearch 规划中） |
| **连接管理** | 层级分组、表单配置、测试连接、SSH 隧道 |
| **SQL 查询** | 当前/新面板运行、查询历史、SQL 格式化、结果表格、单元格内联编辑、分页 |
| **SQL 智能** | 查询编辑器与 `.sql` 文件的上下文补全（表/列/函数/关键字）、片段、EXPLAIN、逐句执行 |
| **表工具** | 数据预览、排序/筛选、增删改、造数、复制、导出 |
| **设计与对比** | 可视化表设计、DDL 查看、ER 图、Schema 对比 |
| **数据迁移** | CSV/JSON 导入导出，带字段映射 |
| **云同步** | 账号登录、AES-256-GCM 加密配置跨设备同步（凭据不出本机） |
| **用户与权限** | 建用户、授权/回收、改密 |
| **国际化** | 中文 / English，默认跟随 VS Code 显示语言 |

## 使用场景

1. **日常查询**：连接后新建查询，Ctrl+Enter 立即执行，结果表格内直接改单元格。
2. **表结构维护**：右键表 → 设计表 / 查看 DDL / ER 图，对比两个库的 Schema。
3. **数据迁移**：导入 CSV/JSON 快速灌数据，或把表导出为 SQL/CSV/JSON。
4. **多设备同步**：登录并配置同步服务器，把连接配置（不含密码）加密同步到其他设备。

## 安全与合规

- 连接密码存于 VS Code `SecretStorage`，云同步只上传**加密数据体**且不含凭据。
- 危险语句（无 WHERE 的 DELETE / DDL）执行前二次确认；只读连接强制只读。
- 详见 [技术文档](./技术文档.md#5-安全设计现状)。
