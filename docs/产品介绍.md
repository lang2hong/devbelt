# DB Client 产品介绍

DB Client 将数据库开发工作集成到 VS Code，减少编辑器与独立数据库工具之间的切换。

## 当前能力

| 能力 | 说明 |
|---|---|
| 多数据库 | 连接 MySQL、PostgreSQL 和 SQLite |
| 查询 | SQL 编辑、补全、格式化、执行、取消和 EXPLAIN |
| 数据操作 | 表预览、筛选排序、结果编辑、导入导出和数据对比 |
| 结构工具 | 表设计、DDL、ER 图和 Schema 对比 |
| 本地安全 | 敏感凭据存入 VS Code `SecretStorage`，支持只读与生产环境保护 |
| 账号与设备 | 注册、邮箱验证、登录、令牌轮换、改密和设备撤销的服务端能力 |
| 组织协作 | 扩展内的组织目录、共享查询和连接模板；组织、成员和邀请的服务端 API |

## 开发中

个人连接同步用于在同一账号的设备间端到端加密同步连接配置。服务端状态、加密记录、签名、nonce、幂等回执、配额和重置协议已经实现；扩展端尚缺完整同步循环、密钥生命周期界面、冲突恢复和双设备验收。

平台运营后台和组织管理后台处于设计与待实施状态；支付、资源 ACL、资源版本、账号删除和组织内容加密尚未实现。后台的职责和权限边界见[管理后台架构](管理后台架构.md)。

同步工作的范围和验收见[个人同步路线图](个人同步路线图.md)。
