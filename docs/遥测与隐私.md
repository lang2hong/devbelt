# 遥测与隐私

本文是 DevBelt 遥测数据项、账号关联与保留策略的完整说明。README 只保留摘要，本文是事实源；采集项、关联方式或保留策略变化时必须同步更新。

## 1. 安装 / 活跃心跳

端点：`POST /api/db/telemetry/heartbeat`（公开接口，无需登录）。

**请求体只有 10 个字段**：

| 字段 | 说明 |
|---|---|
| `installId` | 新安装为**设备公钥指纹派生的 UUID**（每安装一个，不暴露原始硬件 ID）；升级前已有随机 UUID 的安装继续使用旧值，账号切换不重置 |
| `appVersion` | 扩展版本 |
| `vscodeVersion` | VS Code 客户端版本（`vscode.version`） |
| `os` / `arch` | 扩展宿主操作系统（`process.platform`）与架构 |
| `osVersion` | 扩展宿主系统内核/系统版本（Node `os.release()`） |
| `isRemote` | 是否为远程窗口（远程窗口记录的是远端扩展宿主环境） |
| `clientName` | 编辑器宿主产品名（`vscode.env.appName`，如 Visual Studio Code / Cursor / Kiro / Qoder）；产品标识，不是用户标识 |
| `clientScheme` | 编辑器宿主 URI 协议名（`vscode.env.uriScheme`，如 vscode / cursor / kiro / qoder）；`clientName` 缺失时用于兜底归集 |
| `engines` | 当天使用过的数据库引擎枚举（`MYSQL` / `MARIADB` / `PG` / `SQLITE` / `REDIS` / `ELASTICSEARCH` / `MSSQL` / `MONGODB`），最多 8 个；**不含连接名、主机、端口、库名、用户名或 SQL**。旧客户端不传 |

**安装事件**：同一个 `installId` 首次成功上报时记录 `first_seen`，终身一次；也就是“首次激活”，不是 Marketplace 的下载安装数。

**活跃事件**：每个 UTC 日通常一次。触发点包括扩展激活，以及用户实际操作（SQL 执行成功、连接建立成功、AI Chat 发送）；客户端按 UTC 日去重。若当天已上报过、但之后又使用了新的数据库引擎，客户端会补发一次心跳把新引擎带上（服务端按天合并，活跃/安装计数不受影响）；因此同一安装一天的请求上限为 10 次。

**数据库引擎**：只统计“当天用过哪些引擎”，用于回答“哪种数据库的活跃用户更多”。客户端在连接成功时记录引擎枚举（查询必然先连接），心跳携带当天集合；服务端把它合并进当天的活跃行（逗号分隔）。它是固定枚举，不含连接标识；旧版本或未开启遥测的客户端不计入。

**客户端归集**：服务端派生出 `client_family` 并落库，归入 `vscode / cursor / kiro / qoder / windsurf / trae / vscodium / other / unknown`。规则是产品名优先；若产品名是通用 “Visual Studio Code”、但协议名指向已知的非 vscode 客户端（cursor / kiro / qoder 等），以协议名为准。原始 `clientName · clientScheme` 保留在库中；后台原始组合只展示 Top 8，家族总数以固定基数聚合为准。两字段都为空的旧客户端在家族统计中归入 `unknown`（后台显示“旧版/未知”）。`other` 表示有值但不在已知清单，后台保留原始值供核对。

**国家/地区**：服务端在心跳请求时用本地离线 GeoIP 库（MaxMind GeoLite2 或 mihomo `Meta-geoip0`）按 `request.ip` 瞬时解析 ISO 3166-1 alpha-2 国家码，写入 `extension_installs.country_code`；**原始 IP 不落库**。这不是用户国籍，只是安装的粗略出口位置；VPN / 代理、公司 NAT、远程窗口都会影响准确性。MMDB 缺失、私有 IP 或解析失败时为 `NULL`，后台显示“未解析”。国家码随安装行长期保留，只保留最后一次已知值，不记录历史迁移轨迹。

**统计口径**：安装/活跃数据仅覆盖**已开启 VS Code 遥测**的客户端。VSCodium 等默认关闭遥测的衍生客户端、企业关闭遥测的环境不会上报，因此后台数字是下限，不是总安装量。扩展不会绕过该开关。国家/地区仅在服务端按 IP 粗略解析，原始 IP 不保存。

**不采集 / 不落库**：邮箱、账号、连接配置、SQL / Schema / 查询结果、文件路径、对话内容、原始 IP 地址、OS machine-id / `vscode.env.machineId` 原始值、用户自填国籍。`engines` 只是 8 个固定枚举，不包含连接名、主机、端口、库名或用户名。`clientName` / `clientScheme` 只描述编辑器产品，不描述用户；`country_code` 是服务端按 IP 粗略推断的结果，不是客户端上报的国籍。

`deviceId`（OS / VS Code 机器 ID）只用于登录/刷新时的设备绑定，不进入心跳或 identify 的安装标识。

## 2. 账号 ↔ 安装 ID 关联

心跳接口不接收 `userId`（公开接口，客户端自报不可信）。登录态由独立接口建立关联：

- `POST /api/db/telemetry/identify`：需要扩展 access token，body 只有 `{ installId }`；
- 服务端从 token 解析 `userId`，写入 `user_install_links`（同一 user+install 幂等，只刷新 `last_seen`）；
- 登录后提交反馈时，反馈成功也会写入关联（`source=feedback`）；
- 未登录时不建立关联；
- 同一个 `installId` 可以被多个账号关联（共享机器/切换账号），表为多对多；
- 客户端永远不发送 `userId`，也不信任客户端身份。

## 3. 存储与保留

| 表 | 内容 | 保留 |
|---|---|---|
| `extension_installs` | `install_id`、首次/最近心跳时间、扩展版本、VS Code 版本、OS/架构、系统版本、是否远程、客户端产品名/协议名/家族、国家/地区码 | **长期保留** |
| `extension_active_days` | `install_id` + UTC 活跃日 + 当天使用过的引擎枚举（`engines`，逗号分隔，可为空） | **长期保留** |
| `user_install_links` | `user_id`、`install_id`、首次/最近关联时间、来源（identify/feedback） | **长期保留**；账号删除时随 FK 级联删除 |

`installId` 与关联记录**不设自动清理**（产品决定）。IP 只作为限流键存在于 `rate_limit_entries`（约 2 小时后清理），并在心跳时瞬时用于 GeoIP 解析；原始 IP 不写入上述遥测表。

## 4. 限流

- 按 IP：1200 次/小时（覆盖公司 NAT/共享出口的集中启动）；
- 按 `installId`：10 次/24 小时（正常每天一次；当天引擎集合变化时最多补发 7 次，另留激活/重试余量）；
- 按用户：identify 60 次/小时。

## 5. 关闭遥测

- 两个开关**都开启**才发送：VS Code 遥测级别为 `all`（`telemetry.telemetryLevel`；扩展读取 `vscode.env.isTelemetryEnabled` 并要求级别是 `all`，因为心跳属于使用数据，`error` / `crash` 档不允许）与 `devbelt.telemetry.enabled`（默认 `true`）。关闭任意一个即停止发送，在会话中途关闭立即生效。
- 0.4.16 起不再在全局遥测关闭时发送，也不再弹出相关提示。
- 默认关闭遥测的衍生客户端（如 VSCodium）不会上报；这是客户端策略，不是扩展可以绕过的开关。后台的安装/活跃数字因此只代表“已上报安装”，不能当作总安装量。
- 关闭后：停止发送心跳与 identify（不再产生新的安装/活跃/关联/国家码数据）；已存储的数据按上表保留。
- 反馈不受该开关影响：反馈本身仍保存提交内容、账号/安装标识与来源 IP（IP 90 天后清除），用于回复与运营；关闭遥测只是不再产生新的心跳/关联/国家码数据。

## 6. 其他服务端数据（非遥测）

- **反馈**：内容、联系方式、附件、账号/安装标识、来源 IP（90 天后清除）。匿名反馈线程的 replyKey 是设备身份派生的秘密（旧安装保留原 replyKey 以读取旧线程）；服务端只存 SHA-256，不存明文。
- **审计日志**：登录、管理操作等事件。
- **AI 请求流水**：模型、token、积分、成本、用户 ID；不存对话文本，保留 180 天。
- **同步记录**：端到端加密的业务密文与元数据（大小/时间/类型）。
- **DevBelt Diagnostics**：本地输出面板，不上传。
