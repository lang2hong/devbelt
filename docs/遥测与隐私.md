# 遥测与隐私

本文是 DevBelt 遥测数据项、账号关联与保留策略的完整说明。README 只保留摘要，本文是事实源；采集项、关联方式或保留策略变化时必须同步更新。

## 1. 安装 / 活跃心跳

端点：`POST /api/db/telemetry/heartbeat`（公开接口，无需登录）。

**请求体只有 7 个字段**：

| 字段 | 说明 |
|---|---|
| `installId` | 客户端首次使用时生成的随机 UUID v4，每台机器 / 每个 VS Code Profile 一个，账号切换不重置 |
| `appVersion` | 扩展版本 |
| `vscodeVersion` | VS Code 客户端版本（`vscode.version`） |
| `os` / `arch` | 扩展宿主操作系统（`process.platform`）与架构 |
| `osVersion` | 扩展宿主系统内核/系统版本（Node `os.release()`） |
| `isRemote` | 是否为远程窗口（远程窗口记录的是远端扩展宿主环境） |

**安装事件**：同一个 `installId` 首次成功上报时记录 `first_seen`，终身一次。

**活跃事件**：每个 UTC 日最多一次。触发点包括扩展激活，以及用户实际操作（SQL 执行成功、连接建立成功、AI Chat 发送）；客户端按 UTC 日去重。

**不采集**：邮箱、账号、连接配置、SQL / Schema / 查询结果、文件路径、对话内容、IP 地址。

## 2. 账号 ↔ 安装 ID 关联

心跳接口不接收 `userId`（公开接口，客户端自报不可信）。登录态由独立接口建立关联：

- `POST /api/db/telemetry/identify`：需要扩展 access token，body 只有 `{ installId }`；
- 服务端从 token 解析 `userId`，写入 `user_install_links`（同一 user+install 幂等，只刷新 `last_seen`）；
- 登录后提交反馈时，反馈成功也会写入关联（`source=feedback`）；
- 未登录时不建立关联；
- 同一个 `installId` 可以被多个账号关联（共享机器/切换账号），表为多对多；
- 客户端永远不发送 `userId`，也不信任客户端身份。

## 3. 存储与保留

| 表 | 内容 | 保留 |
|---|---|---|
| `extension_installs` | `install_id`、首次/最近心跳时间、扩展版本、VS Code 版本、OS/架构、系统版本、是否远程 | **长期保留** |
| `extension_active_days` | `install_id` + UTC 活跃日 | **长期保留** |
| `user_install_links` | `user_id`、`install_id`、首次/最近关联时间、来源（identify/feedback） | **长期保留**；账号删除时随 FK 级联删除 |

`installId` 与关联记录**不设自动清理**（产品决定）。IP 只作为限流键存在于 `rate_limit_entries`（约 2 小时后清理），不写入上述遥测表。

## 4. 限流

- 按 IP：1200 次/小时（覆盖公司 NAT/共享出口的集中启动）；
- 按 `installId`：5 次/24 小时（正常每天最多一次，其余为失败重试余量）；
- 按用户：identify 60 次/小时。

## 5. 关闭遥测

- 开关：`devbelt.telemetry.enabled`（默认 `true`），只由扩展自身控制，独立于 VS Code 全局遥测开关。
- 首次激活时如果检测到 VS Code 全局遥测关闭，会给出一次提示，可一键关闭。
- 关闭后：停止发送心跳与 identify（不再产生新的安装/活跃/关联数据）；已存储的数据按上表保留。
- 反馈不受该开关影响：反馈本身仍保存提交内容、账号/安装标识与来源 IP（IP 90 天后清除），用于回复与运营；关闭遥测只是不再产生新的心跳/关联数据。

## 6. 其他服务端数据（非遥测）

- **反馈**：内容、联系方式、附件、账号/安装标识、来源 IP（90 天后清除）。
- **审计日志**：登录、管理操作等事件。
- **AI 请求流水**：模型、token、积分、成本、用户 ID；不存对话文本，保留 180 天。
- **同步记录**：端到端加密的业务密文与元数据（大小/时间/类型）。
- **DevBelt Diagnostics**：本地输出面板，不上传。
