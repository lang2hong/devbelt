# P6 安全评审清单（验证器多设备同步 / 网页版）

> 依据 P6 阶段文档 §十「安全与隐私」与 §十二「验证」。S7 收尾逐项核对；S5 完成后回填。

## 1. 密钥生命周期
- [ ] DEK 仅内存（扩展：SecretStorage 持久化；Web：仅内存、登出即清，无 sessionStorage/localStorage）。
- [ ] Argon2id 只在 Worker（扩展）/ WASM（Web）执行，主线程不引入 `hash-wasm`；参数与扩展 SMP **同构**且来源单一。
- [ ] 换钥/恢复/销毁/重置后旧 epoch DEK 与本地同步产物被清理，幂等可续跑。

## 2. 日志与错误
- [ ] 不记录 secret / `otpauth` URI / 密文 / 明文 payload；错误消息不含敏感值。
- [ ] 后台/控制台只聚合元数据，不返回密文或明文。

## 3. 元数据披露
- [ ] 明确披露：`entity_kind` + `change_sequence`/时间可推断「用户何时新增验证器条目」的时间元数据。
- [ ] 后台 UI 与文档同步说明「内容端到端加密，后台不可见」。

## 4. 协议与发布顺序
- [ ] `entityKind` 为**可选**字段；发布顺序「先服务端（接受该字段）后客户端」。
- [ ] 旧客户端×新服务端、新客户端×旧服务端 兼容用例通过。
- [ ] `entityKind` 白名单校验（未知值拒绝），防改标签绕过按类型配额。

## 5. 配额与对账
- [ ] 服务端按 `maxAuthenticatorEntries` 强校验（客户端门禁可被绕过，以服务端为准）。
- [ ] 客户端配额拒绝 → 终态不重试 + 标 `localOnly/quota` + UI 提示升级；推送成功清标记。
- [ ] `localOnly/syncError` **不进同步 payload**（避免随整条 LWW 被覆盖）。

## 6. CSP（仅 Web / `db-ui`）
- [ ] `db-ui`（浏览器应用）允许 `wasm-unsafe-eval` 与 `worker-src`；扩展 `webview/html.ts` **无需改**。
- [ ] 不新增 `img-src` 放宽（验证器二维码图片录入在扩展侧，Web 端不涉及）。

## 7. 打包验收
- [ ] `pnpm -C apps/vscode-ext package` 成功。
- [ ] 控制台（db-ui/admin-ui/auth-ui）构建成功。
- [ ] 双设备真机验收（见 `剩余任务.md` P6 发布硬门禁）。
