## 文档规则

- 架构文档只描述**代码中真实存在**且已接线的事实；未来方案写在对应阶段文档里。
- 功能状态以 VSIX 安装版 smoke test 为准，单元测试/typecheck/CI 是发布门槛，不替代功能验收。
- 阶段文档是该阶段唯一的实施权威；路线图只排顺序不重复实现细节。
