## 当前阶段顺序

| 阶段 | 目标 | 完成定义 |
|---|---|---|
| P0 | 确认扩展在 VSIX 安装后核心本地路径可用 | Clean Profile 安装 + MySQL/SQLite 全流程可跑，命令/菜单/视图零空注册，无明文密码泄露 |
| P2 | 同账号多设备安全同步个人数据（连接、分组、保存查询、查询文件夹，树完全一致） | 双设备双 Profile 验收矩阵全通过，协议修复、引擎+接线、初始化/解锁 UI、自动同步（可开关，默认关）、冲突解决、改密码/恢复/销毁/重置闭环 |
| P3 | 浏览器 Console UI 管理后台 | 账户、设备、运营后台同源托管 |
| P4 | 支付闭环 | 微信/支付宝回调、订单状态机、权益生效、对账 |
| P5 | 本地 2FA/TOTP 验证器（webview 面板，不占活动栏） | 算法向量/功能/安全边界/i18n 全绿；Clean Profile 安装版手工走查通过 |
| P6 | 验证器多设备同步与网页版 | E2EE 同步实体 + 服务端配额 + Web 解锁解密全链路通过 |
| P7 | Redis 客户端（对齐 ARDM 核心体验） | 连接/服务器状态/CLI 控制台/键浏览/五类型 CRUD/Stream/Cluster/Sentinel + SSH NAT map；SQL 路径零回归 |
| P8 | Elasticsearch 客户端（对齐 es-client 核心体验） | 连接/集群总览/索引浏览/mapping/文档 CRUD/DSL 查询/REST 控制台；P7 引擎接缝零回归 |

## 阶段依赖

P2 依赖 P0 的账户/认证/权益基础。P3 依赖 P2 服务端协议稳定。P4 依赖 P3 可管理订单与权益。
P7（引擎接缝+Redis）在 P6 之后，依赖现有 SQL 连接/凭据体系但不依赖同步。
P8（ES）依赖 P7 引入的 EngineKind/ConnectionSession 判别联合，复用同一接缝。

## 文档事实规则

- 阶段文档是该阶段的唯一权威规格，路线图不再描述实现细节。
- 架构文档仅记录当前代码事实，不描述未来方案。
- 产品介绍仅记录用户可见能力状态，不承载设计。
- 静态注册测试不等于安装版可用；Clean Profile VSIX smoke test 是 P0 发布的必要条件。
