# DB Client 开发文档

## 环境

- Node.js 20 或 22
- pnpm（通过 corepack 管理）
- VS Code
- Docker 与 MySQL 8，用于服务端集成测试

## 安装与验证

```bash
pnpm install
pnpm build
pnpm typecheck
pnpm lint
pnpm test
```

包级命令：

```bash
pnpm -C packages/db-core build
pnpm -C packages/db-core test
pnpm -C packages/vscode-ext typecheck
pnpm -C packages/vscode-ext test
pnpm -C packages/vscode-ext package
pnpm -C packages/server typecheck
pnpm -C packages/server test
pnpm -C packages/server build
```

服务端集成测试使用 `MYSQL_TEST_URL`。数据库名称必须包含 `test` 或 `verify`，且不能与运行数据库相同。

## 调试

1. 用 VS Code 打开仓库根目录。
2. 选择扩展调试配置。
3. 按 F5 启动 Extension Development Host。

本地运行服务端：

```bash
cd packages/server
cp .env.example .env
docker compose up -d
```

`.env`、私钥、密码和 token 不得提交。

## 变更要求

- 数据库驱动与查询逻辑放在 `db-core`。
- VS Code 生命周期、界面和本地状态放在 `vscode-ext`。
- 身份、授权、协议和持久化放在 `server`。
- 用户可见文案进入国际化目录。
- 修改数据模型、API、权限、安全或同步协议时更新[实施规格](实施规格.md)并补充测试。
- 改动扩展入口、命令或打包内容时生成 VSIX 并完成安装冒烟测试。
