# P0 — 安装版可用性

## 目标

确认扩展在 VSIX 安装后核心本地路径可用。当前命令注册与菜单 when 测试只验证静态接线，不等于安装版功能验收；Clean Profile VSIX smoke 是 P0 发布的硬条件。

## 范围

### 修复项（P0 内必须完成）

1. **PostgreSQL 权益缓存缺陷**
   - 现状：`AuthService.setCachedEntitlement()` 在整个代码库中零调用点；`auth.init()` 不从服务端拉取 `/api/me`；AccountView/SessionView 虽然调用 `client.getMe()` 但只将结果 post 到 webview，同样不调用 `setCachedEntitlement()` 写入缓存。因此 `devbelt.sync.cachedEntitlement` 始终为空，`ConnectionManager` 的 PG 门禁 fail-closed 到 Free（mysql/sqlite），PG 连接始终被拒——即使登录后打开账户面板也无法临时修复。
   - 修复：`AuthService` 新增 `refreshEntitlement()` 方法，调 `/api/me` 并 `setCachedEntitlement()`；`auth.init()` 在 token 有效后调用 `refreshEntitlement()`（失败不阻塞登录，仅降级到 Free）；AccountView/SessionView 打开时调用 `refreshEntitlement()`；未登录状态下本地 PG 连接不应被付费门禁拦截（本地 PG 无需登录，权益门禁仅用于付费能力，本地 PG 是否 Free 可用由产品决定，本阶段至少保证本地 MySQL/SQLite 无登录可用）。
   - 验收：登录前可新建/连接 MySQL、SQLite；登录后 PG 权益按 `/api/me` 返回生效，非登录用户不因空缓存被误拒。

2. **Clean Profile 打包完整性验证**
   - esbuild 产物包含 extension.js、argon2Worker.js、所有 Webview HTML；主线程 bundle 不含 `hash-wasm`（bundle isolation 测试已覆盖，需验证 VSIX 内同样成立）。
   - `.vscodeignore` 未误排除 Worker、Webview、图标等资源。

### 验证矩阵（每项必须 pass/fail/skipped 并标注原因）

| 分类 | 验证项 |
|---|---|
| 安装与激活 | 安装后无 activation failed；视图 `devbelt.explorer` 可见；命令面板列出所有声明命令，无空命令 |
| 连接管理 | 添加/编辑/删除连接；分组增删改/层级移动；测试连接；SSH 隧道（密钥路径/密码两种）；打开/关闭连接 |
| SQL 编辑 | SQL 语法补全；CodeLens；格式化；执行选中/全文；多语句执行；取消执行；EXPLAIN |
| 结果视图 | 表格展示；排序；筛选；受控行内编辑；多结果集；大结果集分页 |
| 数据操作 | CSV/JSON/XML/XLSX 导入导出；SQL dump 导出/还原；库间数据传输 |
| 结构工具 | 表设计器；DDL（建/改/删表/列/索引/外键/触发器/视图/例程/事件，注意 MySQL/SQLite capability 差异） |
| Schema 工具 | Schema 对比、同步 SQL 生成（当前引擎范围内） |
| 辅助功能 | 查询历史、审计日志、定时备份、连接池状态、服务器仪表盘、ER 图、对象搜索、终端集成 |
| 国际化 | 中/英文切换；所有命令与 Webview 文案加载 |
| 凭据安全 | 密码存入 SecretStorage 而非 Memento；登出/卸载不留明文；生产环境写保护提示 |

### 不在 P0 范围

- PostgreSQL 付费权益正式上线（需权益规则和套餐定义，PG 本地直连在 P0 内至少做到不因空缓存崩溃，但完整 PG 支持可与 P1 权益流一起落地）。
- 个人同步 UI 接线。
- 浏览器控制台与支付。

## 实施顺序

1. 修复 PostgreSQL 权益缓存：
   - `AuthService` 增加 `refreshEntitlement()` 方法，调 `/api/me` 并 `setCachedEntitlement()`。
   - `auth.init()` 在 token 有效后调用 `refreshEntitlement()`（失败不阻塞登录，仅降级到 Free）。
   - AccountView/SessionView 打开时调用 `refreshEntitlement()`（当前这两个 View 只 getMe 不写缓存，需补上）。
   - `ConnectionManager` 懒加载 getter 在无缓存时不自动拒 PG：明确本地连接不走权益门禁（权益门禁用于同步配额，本地引擎支持看方言是否注册）。
2. 修复 VSIX 打包：
   - 用 `pnpm -C apps/vscode-ext package` 生成 `.vsix`，解压检查 assets。
   - 确认 `.vscodeignore` 未排除 Worker/Webview/图标。
3. 执行 Clean Profile smoke：
   - `code --extensions-dir <clean-ext> --user-data-dir <clean-data> --install-extension *.vsix`。
   - 按验证矩阵逐项执行并记录 pass/fail。
4. 失败项修复后回归。

## 验收

- 新安装、未登录用户可完成 MySQL + SQLite 本地连接与 SQL 执行全流程。
- `pnpm -C apps/vscode-ext test` 100% 通过；`pnpm -r run typecheck` 通过；`pnpm -C apps/server test` 通过。
- `commandRegistration.test.ts`、`menuWhen.test.ts`、`bundleIsolation.test.ts` 100% 通过。
- Clean Profile 验证矩阵全部 pass（PG 项按本阶段范围执行）。
- 无 production 环境明文密码泄露、无空命令、无视图加载失败、无 Webview 资源 404。
