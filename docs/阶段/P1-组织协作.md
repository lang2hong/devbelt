# P1 — 组织协作

## 目标

登录后组织相关功能完整可用：组织树自动出现、共享查询 CRUD 完整、连接模板可建立临时连接、角色与权限在 UI 上一致表达、登出干净清理。

## 范围

### 必做项

1. **登录后自动刷新组织树**
   - 现状：`extension.ts` 订阅 `AuthEvent('login')` 时只设置 `dbclient.loggedIn`，未触发 `orgTreeProvider.refresh()` 或 `orgWorkspace.select(ws)`。树在用户手动展开时懒加载，首次登录后看到的是"请先登录"占位。
   - 实现：登录成功后调用 `orgWorkspace.select(defaultOrg?)`（选择第一个组织或无组织占位），触发 `onDidChange` → `tree.refresh()`；登出时已有 `clearAuth()` 清理并回到占位。

2. **组织查询 CRUD 完整**
   - 现状：`openResource`、`newQuery`、`saveResource`、`deleteResource`、`newFolder`、`deleteFolder` 命令已注册，但 `dbclient.org.saveResource` 和 `dbclient.org.runQuery` 无菜单入口（不在 view/title、view/item/context、editor/title），只能命令面板调用。
   - 实现：
     - 在组织 SQL 编辑器标题栏和命令面板添加 `when` 子句：`dbclient.orgResourceEditor == true`（打开的是组织查询编辑器）。
     - 保存 409 版本冲突保留本地编辑（服务端已返回 RESOURCE_VERSION_CONFLICT，当前代码已 catch 但 UI 未给冲突提示，需弹"远端已更新，是否覆盖/刷新"）。
     - 新建查询默认进入选中目录；无选中目录时提示选择位置。

3. **连接模板建立临时连接**
   - 现状：`toSavedConnection()` 硬编码 `DatabaseType.MYSQL`，SSL 仅读 mode 推导 `useSSL:boolean`，忽略 `databaseType` 和 `ssl.rejectUnauthorized`；`ConnectionConfig` 无 `rejectUnauthorized` 字段，PG 驱动硬编码 `rejectUnauthorized:true`，MySQL 驱动不设该字段；模板内服务端禁止密码/SSH 字段，密码等本机凭据走 `CredentialVault`。
   - P1 范围内的明确决定：
     - **P1 仅支持 MySQL 连接模板**。服务端已对 `databaseType` 按订阅白名单做引擎允许性校验，P1 模板 UI/创建不在范围，因此客户端对 `databaseType !== 'mysql'` 的模板展示"当前版本不支持"提示，不尝试建连。
     - SSL 模式：`disable`→`useSSL:false`；`require`→`useSSL:true` 且不校验证书；`verify-ca`/`verify-full`→需 CA 路径（本机配置，由用户在本机临时会话中选择 CA 文件，不保存到全局配置）；`rejectUnauthorized` 在底层补 `ConnectionConfig.rejectUnauthorized?: boolean` 字段并透传到 mysql2/pg 驱动。P1 对 verify-ca/verify-full 显示"请提供 CA 证书"提示即可，不强制做证书管理 UI。
   - 不在 P1：模板创建/编辑 UI、PostgreSQL 模板、SSH 私钥路径管理（仅本机 vault 字段，不保存路径）。

4. **角色感知菜单**
   - 现状：`WorkspaceRef.role` 是 `'admin'|'member'`，但从未通过 `vscode.commands.executeCommand('setContext', …)` 导出到 VS Code context；所有组织菜单 when 只匹配 view/viewItem，member 角色也看得到新建/删除/保存菜单项，点击后由服务端 403 拒绝。
   - 实现：
     - 选择组织后 `setContext('dbclient.orgRole', role)`；clearAuth 时 `setContext('dbclient.orgRole', undefined)`。
     - 菜单 when 子句中：新建/删除/保存类命令加 `dbclient.orgRole == 'admin'`（folder.manage/resource.write 需要 admin）；只读命令（openResource、connectTemplate、runQuery）不限角色。
     - commandPalette 中组织命令加 `dbclient.loggedIn && dbclient.orgRole`（member/admin 均可），未登录不显示。

5. **错误与未登录/无组织状态提示**
   - 401：`OrgWorkspace` 的 error handler 已有 `clearAuth()` 回退个人空间；需显示"登录已过期，请重新登录"通知。
   - 403：被服务端拒绝（如 member 写操作被 UI 漏拦时）显示"无权限执行此操作"。
   - 无组织：组织树显示"暂无组织，可创建或加入组织"引导（服务端创建组织接口已存在，但创建组织 UI 不在 P1——显示文案链接到后续阶段）。
   - 登录过期：清除本机凭据 vault（`CredentialVault.clearOrg()`），不残留旧密码。

6. **登出清理**
   - 现状：logout 时 `clearAuth()` 清工作区缓存，但未显式清 `CredentialVault` 凭据；下次登同账户仍能看到旧密码。
   - 实现：logout 时调用 `credentialVault.clearAll()`（或按 orgId 逐个删），确保本机凭据不出现在重新登录/切换账号之后。

### 不在 P1 范围

- 组织模板的创建/编辑 UI（后续 P1.x/P3）。
- PostgreSQL/SQLite 连接模板（等 P3 或专门的模板管理阶段）。
- SSL 证书本地管理 UI（仅提供文件选择器即可，不持久化）。
- 组织邀请/成员管理的浏览器界面（P3 Console UI）。
- 成员/角色管理的本地操作 UI（当前仅服务端 API 可用，没有 UI 入口）。

## 实施顺序

1. 补底层 SSL 透传：
   - `ConnectionConfig` 增加 `rejectUnauthorized?: boolean`。
   - MySQL/PG/SQLite 驱动读取该字段（PG 现有硬编码改为默认 true、可由配置覆盖；MySQL 透传到 mysql2 ssl 选项）。
2. 修复登录刷新：`extension.ts` 订阅 `AuthEvent('login')` 后调用 `orgWorkspace` 选默认组织。
3. 导出角色 context：`WorkspaceRef` 选择后 `setContext('dbclient.orgRole', role)`，clearAuth 清空。
4. 菜单 when 子句与命令面板上下文：
   - package.json 添加/修正：新建/删除/保存类命令加 `dbclient.orgRole == 'admin'`；所有组织命令加 `dbclient.loggedIn`；组织编辑器命令加 `dbclient.orgResourceEditor`。
5. `toSavedConnection()`：
   - 读 `databaseType`，非 mysql 返回明确错误提示。
   - 补 `rejectUnauthorized` 透传（仅当 mode === verify-ca/verify-full 时设置，require 模式默认不校验）。
   - 保留现有 SSH/密码仅从本机 vault 读取的行为。
6. 409 冲突提示：`saveResource`/`runQuery` catch 中 RESOURCE_VERSION_CONFLICT 弹对话框给用户"覆盖/刷新/取消"。
7. logout 清理凭据 vault。
8. 错误通知统一：401/403/无组织分别给可读提示。

## 验收

- 登录后无需手动刷新即看到组织树。
- member 角色菜单：无新建/删除/保存入口；admin 角色可见。
- 组织查询：新建、编辑、保存（含 409 冲突提示）、删除、目录移动/删除完整可用。
- MySQL 模板：输入本机密码后可建立会话、执行 SQL、查看结果；非 MySQL 模板显示"当前版本不支持"提示，不崩溃。
- 本机密码/SSH 凭据只保存在 `CredentialVault`（SecretStorage），不写入个人 ConnectionStore，不进入任何出站请求。
- 登出后组织树回占位，vault 凭据清空，重新登录需重新输入密码。
- 401/403/无组织状态有可读提示，不抛未捕获异常。
- 全部现有测试通过；新增角色 when 子句、rejectUnauthorized 透传、toSavedConnection 非 mysql 分支的单测。
