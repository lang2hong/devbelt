## 3. 验证器手工走查（P5）
- [ ] 命令面板执行「验证器」→ 打开面板（**不占活动栏图标**）。
- [ ] 「＋」添加：粘贴 `otpauth://` 链接；手动填表（issuer/account/secret/算法/位数/周期）。
- [ ] 「从图片添加」：粘贴图片 / 拖拽 / 选择文件，均能解析单条二维码。
- [ ] 列表显示 6/8 位口令与倒计时；剩余 ≤5 秒有“即将刷新”警示。
- [ ] 点卡片复制纯数字口令，出现“已复制”反馈；系统剪贴板内容正确。
- [ ] 分组：新建/重命名/删除/上移下移；删组后条目回落「未分组」；折叠/展开不参与 tick。
- [ ] 标签：新建/选色/删除；按标签筛选；条目打多标签。
- [ ] 搜索：按 issuer/account 过滤；三种空态（无条目/搜索无结果/组内空）正确。
- [ ] 编辑：secret 留空表示保留原 secret；填非法 base32 有内联错误。
- [ ] 删除：有二次确认。
- [ ] 导出：弹 modal 明文警告；导出文件为 CRLF、每行一条 otpauth，secret 大写无空格无 padding；`0600` 权限。
- [ ] 中/英切换后文案完整（命令、按钮、空态、错误）。
- [ ] 配额：登录 Free 档达 10 条时点「＋」直接弹「升级 Pro」，不展开空白表单。
- [ ] 安全边界：确认界面/日志不显示 secret。

## 3-补2. PostgreSQL 多 schema/多库（P7.1）发布门禁

- 硬门禁（D28）：CI `integration` job 的 postgres service + `packages/db-core/test/integration/pgMultiSchemaReal.test.ts`（两个 schema，同名表/外键约束/触发器；浏览 / 编辑 / 导出→导入 round-trip / 外键 / 触发器）全绿。
- 机械断言：MySQL 树不出现 Schema 节点；不存在 `pgSchemaFor(…, *.database)`；导入 SQL 脚本在 PG 下设置 `search_path`。
- 范围：PG 多 schema 浏览与写/DDL/导出/数据编辑 + **多库**（可见库枚举、按库懒建会话 4+LRU、隧道引用计数复用、在该库执行）；`public` 置顶、系统 schema 不列、无权限库不列；不提供 `USE`、不支持跨库结构对比。
- 会话/隧道机械断言：`derivedDatabaseSessions.test.ts`（衍生上限、LRU、`disposeConn`、`openCount` 去重）。
- 已知限制：见 `docs/阶段/P7.1-PG多schema与多库.md` §六（参数绑定、跨库结构/数据对比不支持等）。

## 3-补3. Elasticsearch（P8）发布门禁

- 硬门禁：**ES 7/8 真机手工矩阵**（无安全 / Basic / ApiKey / 自签 TLS / SSH × 只读模式，含「只读下 `POST /_nodes/reload_secure_settings` 被拦截」）与面板端到端 UI 走查（Cluster / Indices / Docs / DSL / REST 五 tab），不可自动化。
- 只读语义（fail-closed）：GET/HEAD 恒放行；非 GET 仅 POST 且命中读路径白名单（`_search`/`_count`/`_mget`/`_msearch`/`_field_caps`/`_explain`/`_validate` 与 `/_cat`、`/_cluster/health|stats`、`/_resolve/index|cluster`）；`/_nodes` 管理端点（`reload_secure_settings`/`shutdown`）与 `_bulk` 等一律 403，仅可单条解锁。
- 自动化覆盖：`esClient.test.ts`（只读切面/白名单回归）、`elasticsearchView.test.ts`（危险确认/只读解锁/inflight 并发与 dispose）、树/i18n/catalog 测试。
- 已知限制与手工矩阵：见 `docs/阶段/P8-Elasticsearch客户端.md` 第十/十一节。
