## 编号说明

- `P` 编号是稳定工作包 ID，不是版本号，也不代表阶段连续。
- `P0` 已并入 [发布与运维](../发布与运维.md)。
- `P1` 未单独成文。
- `P9.1` 未展开成独立文档。
- `P11` 为已归档的 SQL Notebook 规格（分支 `dev/p11-workspace`），编号不再复用。
- 已完全交付且验收通过的工作包，后续可直接删除；需要追溯时使用 git 历史。
